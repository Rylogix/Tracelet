# Tracelet

Tracelet is a web workspace for public-source lookups and investigation reports.

**[Open Tracelet](https://tracelet.rylogix.com)** · [Report an issue](https://github.com/Rylogix/Tracelet/issues)

## Run your first investigation

1. **Create an account.** Open the website, select **Get started**, and create a passkey. Sign in with that passkey when you return.
2. **Choose a lookup.** Use the desktop sidebar or mobile bottom bar. Try **Number** with `+442079460018` to see how Tracelet interprets an international phone number. **Username** checks public profiles, **Email** checks domain configuration, **Website** looks up public domain records, and **Files** reads metadata in your browser.
3. **Review the findings.** Expand a finding to inspect its details and follow the original source when available. Treat username matches as leads and use the source evidence to verify them.
4. **Build a report.** Open **Report**, give it a title, and keep the searches you want to include. Download a short **PDF** or export the detailed **TXT**. **Save to history & clear** archives the report and starts a fresh draft.
5. **Review activity and settings.** The **Dashboard** shows recent draft searches, saved reports, and locally recorded requests. In **Settings**, connect an optional VirusTotal key, inspect API usage, and manage local request budgets and alerts. Allowances appear when providers report them.
